A travel poster for a place that does not exist: **KAIROVEL**, a floating archipelago in the sky at golden hour — islands adrift above a sea of clouds, a lighthouse, a waterfall pouring off the edge of the world, and one small airship coming up for air.

Entry for the [make.fun bounty "The Poster for a Place That Isn't There"](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

## Run

```sh
python3 main.py
```

Writes `entry.png` (1024×1024) to the directory named by `MAKEFUN_OUTPUT_DIR`, or `./out` by default. Pure Python standard library, fully deterministic — two runs produce byte-identical output.
